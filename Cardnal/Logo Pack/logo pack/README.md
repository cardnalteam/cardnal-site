# Cardnal Logo & Asset Pack v1.0

Drop-in assets for docs, decks, sites, and app stores.

**For a shared doc (Google Docs, Slides, Notion, Word):** use the PNGs in `/png`.
They have transparent backgrounds, so they sit on any page colour. The 1024px
versions are right for most documents; 2048 if it's a full-width header.

Open `CONTACT-SHEET.png` to see everything at once.

## What's here

| Folder | Contents |
|---|---|
| `/svg` | Vector originals. Infinitely scalable, tiny files. **Text is outlined** — no font needed to open them. |
| `/png` | Transparent PNGs at 512 / 1024 / 2048 (4096 for key assets) |
| `/social` | Square avatars and banners with solid backgrounds |
| `/favicon` | Browser icons 16–512, app icons, and `favicon.ico` |

## The assets

| Asset | Use it for |
|---|---|
| `mark-red` | The wing alone. Favicon, app icon, avatar, anywhere the brand is already established. |
| `logo-horizontal` | **The primary logo.** Document headers, decks, website nav, email signatures. |
| `logo-vertical` | Square spaces — social profiles, merch, event backdrops. |
| `wordmark-black` | "Cardnal" as type, no mark. Footers, body copy, co-branded lockups. |
| `slogan-stacked` / `slogan-oneline` | "The right card. Every time." Second line always in red. |
| `lockup-full` | Mark + wordmark + slogan. Title slides, covers, one-pagers. |
| `avatar-*` | 1:1 profile pictures — white, ink, and red backgrounds. |
| `banner-*` | 1600×600 headers for LinkedIn, docs, and slide backgrounds. |

Every asset comes in three colourways:
- **Default** — red mark, ink text. Use on white or light backgrounds.
- **`-white`** — all white. Use on dark backgrounds, photos, or brand red.
- **`-black`** — all ink. Single-colour print, faxes, engraving.

## Rules that matter

1. **Clear space:** every asset already includes 10% breathing room so nothing looks
   cut off when dropped into a document. For formal use — signage, partner lockups,
   co-branding — allow the full clear space: 40% of the mark's height on all sides.
2. **Minimum size:** mark 20px tall on screen; horizontal lockup 96px wide. Below that, use the mark alone at a larger size.
3. **Three colours only:** brand red `#E60B21`, ink `#0B0C0E`, white. Never any other colour.
4. **Never** stretch one axis, rotate, add shadows or glows, or place the red mark on a red background.

Full rules and rationale: see the Cardnal Brand Design System, section 01.

### A note on the letterforms
In "The right card." the lowercase **h** sits slightly taller than the capital **T**.
That's correct — in Archivo the cap height is 687 units and the ascender is 724, so
lowercase ascenders overshoot capitals by about 5%. Nearly every typeface does this;
it's what makes text look optically even. Nothing is cropped.
